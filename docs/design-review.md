# UI 验收记录

## 风格自检

依据 `DESIGN.md` 的「极简主义 × 浮世绘」规则：

- 装饰：只有登录页 / 工作台的一幅原创海景，不铺重复浪纹。
- 图标堆砌：模块以文字和序号导航，操作图标保留可读名称。
- 阴影：未使用 box-shadow、text-shadow 或滤镜阴影。
- 写实光影：主视觉使用平涂色块和细线。
- 霓虹色：界面只用规定的纸色、墨色和单一普鲁士蓝强调色。
- 3D：没有立体变换、拟物透视或浮雕效果。
- 大面积渐变：没有渐变背景、渐变文字或玻璃效果。
- 动效：仅透明度反馈；尊重减少动态效果设置，列表定位不做平滑滚动。
- 框架与认证：未增加依赖，未修改生产 API、Token 读取或线上密码校验。

## 已执行验证

- `npm run check`：生产 API 与前端 JavaScript 语法检查。
- `node tests/post-editor.test.mjs`：原有 7 项文章/源码/日期保存用例，以及 2 项未保存确认用例。
- `node tests/fixtures/preview-smoke.mjs`：13 项演示服务隔离、HTTP、内存保存与访问限制用例。
- `npm run build`：静态输出生成。
- `git diff --check`：补丁空白检查。

浏览器使用隔离演示服务验证了：1440px 桌面布局、390px 手机布局、11 类站点设置表单、相册编辑、图形化更新日期保存、完整源码更新日期保存、取消离开保留编辑、日夜模式、演示登录、手机目录收起及导航 Escape 关闭。检查的页面未发现横向溢出；保存操作没有发送到 GitHub。
