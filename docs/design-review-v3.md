# 个人编辑台 · 本地验收

本版使用极简主义骨架、浮世绘表皮。按用户追加要求，页面由暖黄纸色调整为画卷米白 `#f7f4ec`，次级面板为 `#efeae0`。这是对 style-mix 原纸色的明确调整；蓝色强调、排版与交互规则保留。

## 页面与流程

- 顶部文字导航，居中单栏任务视图；首页优先继续真实草稿。
- 版画为生成并落地的 `public/assets/ukiyo-editorial-v3.png`，3:2 完整显示；仅首页一幅。
- 文章在同一表单中切换写作、预览与发布设置；高级源码保留。
- 返回目录保留搜索；手机菜单选择完成后聚焦主内容。
- 首次访问默认米白日间模式，手动主题选择会保存。

- 通过：没有重复浪纹或界面装饰，母题只在独立版画中。
- 通过：模块以文字导航，没有图标堆砌。
- 通过：无阴影、零圆角、1px 分隔线。
- 通过：无写实界面光影、霓虹、3D 或大面积渐变。
- 通过：无玻璃卡片和渐变文字。
- 通过：仅透明度过渡，并尊重减少动态效果设置。
